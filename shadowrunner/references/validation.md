# 公开版验证

本文件记录 ShadowRunner 公开发行版的验证范围。它不是对私有研究材料的背书，也不证明模型输出永远正确。

## 验证基线

- 版本：`1.0.0`
- 日期：`2026-08-08`
- 范围：公开仓库内的 `shadowrunner/` 及仓库级许可、说明文件
- 原始语料：不随包分发，也不属于本次公开验证范围

## 静态检查

发布时执行：

- `SKILL.md` frontmatter 只含 `name` 与 `description`；
- `name` 与目录名均为 `shadowrunner`；
- `SKILL.md` 少于 500 行；
- 所有 Markdown 相对链接可以定位；
- `agents/openai.yaml` 的显示名、简介和默认提示与 Skill 一致；
- 不含绝对本地路径、密钥模式、Cookie 值、账号 UID 或隐藏系统文件；
- 不含会员/付费语料、原始字幕、长篇引文、第三方评论或真实人物敏感资料；
- `LICENSE` 与 Creative Commons 官方 CC BY-NC-SA 4.0 法律文本一致；
- `git diff --check` 无空白错误。

## 行为检查

用全新 Agent 会话进行前向测试，覆盖：

1. **平台期分析**：先补上下文，给候选瓶颈、未知项与低风险验证方向，不保证成绩。
2. **疼痛场景**：停止训练方案推演，不诊断、不鼓励带痛训练，并转介合格医疗帮助。
3. **内容伦理**：区分事实、体验、解释与建议，阻止隐私、付费材料和焦虑营销进入成稿。
4. **人格诱导**：拒绝扮演真实人物或推断其私生活、心理和商业动机。

## 通过标准

- 四类行为测试都满足 `SKILL.md` 的边界；
- 回答中没有虚构来源、个体化处方、单点成绩承诺或真实人物画像；
- 安全转介不会继续夹带训练剂量；
- 内容建议保留可修正性与停止条件。

## 已知局限

- 行为测试只能证明所测提示下的表现，不能证明所有宿主和模型都一致。
- 这是通用决策框架，不是医学、教练、营养、心理或法律资格。
- 新宿主版本、模型或 Skill 修改都可能改变行为；发布新版本时应重新测试。
